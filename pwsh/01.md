# 鈴鹿黒窓小噺  
## 黒窓、思ってたのと違った？

前回は、とりあえず黒い窓を開いて、いくつか命令を打ってみました。

今回はもう少しだけ先へ進んで、

**「この黒窓で、いったい何を材料にして仕事ができるの？」**

というところを見てみましょう。

---

## 先日の小噺を少し振り返ってみよう

まずは前回と同じようにターミナルを開いてください。

そして、

**上矢印キー `↑`**

を押してみてください。

「あれ？ なんか出てきた。」

そうなんです。

前回打ち込んだコマンドたちを覚えているんです。

賢いでしょ。

何度も同じものを最初から入力する必要はありません。

出てきたコマンドを左右の矢印キーで移動して、一部分だけ書き換えることもできます。

この先、この機能にはずいぶん助けてもらいます。

---

## どんなデータを扱えるのかな？

まずは難しいことを考えず、黒窓にいろいろ入れてみましょう。

```powershell
1..10
```

これは1から10までの数字。

```powershell
1,2,5,12.55
```

整数だけでなく、小数も扱えます。

では文字は？

```powershell
"abc","xyz","漢字"
```

もちろん日本語だって大丈夫。

こんなのは？

```powershell
123,"文字",987.123
```

数字と文字を一緒に置くこともできます。

そして、

```powershell
date
```

現在の日付と時刻が出てきます。

---

## とりあえず `| ogv` してみよう

前回登場した `ogv` を、今のデータの後ろにつけてみましょう。

たとえば、

```powershell
1..10 | ogv
```

あるいは、

```powershell
"abc","xyz","漢字" | ogv
```

さっき黒窓に表示されていたものが、別の窓で見えるようになりました。  
なにやら上の項目名を見ると現在表示しているデータのExcelとかでおなじみの型のようなものが見えますね、。  
もう一度、先ほどのdateの内容に|ogvを付けてみてみましょう。  

![date-ogv(.png)](/images/date-ogv.png){: width="800px" }

先ほどまでと違ってずらずらと複数の項目が表示されています。  
dateコマンドレットは単に文字情報で日付を返すだけでなくていろいろなところで使えるオブジェクトと言う形のデータを返すからなんです。詳しくは近々。

このように、この連載では、しばらく

**「何か出てきたら、とりあえず `| ogv` して眺めてみる」**

くらいの使い方をしていきます。

件数が増えて黒窓では見づらくなったときにも便利です。

---

## `date` と `"date"` は同じ？

ここで、ちょっとだけ大事な話。

次の2つを試してみてください。

```powershell
date
```

```powershell
"date"
```

見た目は似ていますが、やっていることは違います。

`date` はPowerShellに対する命令として働きます。

でも、

```powershell
"date"
```

と `" "` で囲むと、これはただの**文字データ**です。

同じように、

```powershell
Get-Process
```

と、

```powershell
"Get-Process"
```

も違います。

前者はコマンドとして働き、後者はただの文字です。

PowerShellが扱っているデータには、実は「これは数字」「これは文字」「これは日付」といった**型**があります。

今は型について詳しく覚えなくても大丈夫。

とりあえず、

**黒窓の中では、命令とデータはちゃんと区別されている。**

くらいに思っておいてください。

## 初めての「変数」

せっかく読み込んだデータです。

この後も何度も使いたい。

そこで登場するのが**変数**です。

難しそうな名前ですが、今は

**「一時的にデータを覚えておく入れ物」**

くらいに考えてください。

上矢印キー `↑` で、さっきの `Import-Csv` を呼び出します。

そして行の先頭へ移動して、

```powershell
$csv =
```

を追加します。

つまり、

```powershell
$csv = Import-Csv ＜CSVファイルのパス＞
```

という形です。

これで、読み込んだCSVのデータを `$csv` という名前の入れ物に置いておけます。

本当に入っているでしょうか？

```powershell
$csv
```

Enter。

出てきました。

では、

```powershell
$csv | ogv
```

どうでしょう。

さっき読み込んだデータを、もう一度ファイルから読み直さなくても使えました。

## 同じ材料を、いろいろな道具に通してみる

ここからは `$csv` を材料にして、後ろにつなぐものを変えて遊んでみます。

まずは、

```powershell
$csv | Select-Object
```

次は、

```powershell
$csv | Sort-Object
```

そして、

```powershell
$csv | Measure-Object
```

さらに、

```powershell
$csv | Where-Object
```

「あれ？ 何も変わらない」

「これは何を指定すればいいの？」

そんなものもあります。

それでOKです。

これらは後の回で少しずつ使い方を覚えていきます。

今日は、

**同じ `$csv` という材料でも、パイプ `|` の後ろにつなぐ道具を変えられる**

ということだけ見ておきましょう。

そして結果が長くて見づらければ、

```powershell
| ogv
```

を最後につけて眺めてみてください。

## 必要なデータだけ別の箱へ

では、少しだけ加工らしいことをしてみます。

たとえば、このCSVから18歳～40歳の人だけを取り出してみましょう。

```powershell
$justzone = $csv | Where-Object { $_.年齢 -ge 18 -and $_.年齢 -le 40 }
```

※ `年齢` の部分は、配布するCSVの実際の項目名に合わせてください。

ちょっと急に暗号っぽくなりましたね。

今は全部理解しなくて大丈夫です。

やっていることは、

**「`$csv` から18歳～40歳だけを選んで、`$justzone` という別の入れ物に入れた」**

だけです。

確認してみます。

```powershell
$justzone | ogv
```

人数も見てみましょう。

```powershell
$justzone | Measure-Object
```

## 全部打ち直さなくていい

ここでも履歴を使いましょう。

さっき、

```powershell

```

と打っていたなら、上矢印キーで呼び戻せます。

そして `$csv` の部分だけを、

```powershell
$justzone
```

に書き換えればいい。

さらに楽をするなら、`$justzone` を選択して `Ctrl+C`。

履歴から以前のコマンドを呼び出して `$csv` の部分を選択し、`Ctrl+V`。

```powershell
$csv | ogv
```

が、

```powershell
$justzone | ogv
```

に変わりました。

後ろの道具はそのまま。

**材料だけ差し替えた**わけです。

これ、なかなか便利だと思いませんか？

# 今回はここまで

今回は、

数字や文字を黒窓に置いてみるところから始めて、

CSVという少し大きなデータを読み込み、

変数に覚えさせ、

パイプの後ろにつなぐ道具を変えたり、

まだ、それぞれのコマンドレットを詳しく理解する必要はありません。

まず覚えてほしいのは、

**材料を用意する → パイプで道具につなぐ → 結果を見る**

そして、

**材料も道具も差し替えられる**

ということ。

黒窓が少し「仕事をする場所」に見えてきたでしょうか。

## 本日の用語集

### `Import-Csv`

CSVファイルをPowerShellに読み込むコマンドレット。

### 変数

データを一時的に覚えておく入れ物。

PowerShellでは `$csv` のように、名前の先頭に `$` をつけます。

### パイプ `|`

左側の結果を右側へ渡すもの。

この先、何度も登場します。

### `Out-GridView` / `ogv`

データを別のウィンドウで表のように眺めるためのコマンドレット。

`ogv` は `Out-GridView` の短い呼び方です。

### `Select-Object`

データから必要な項目などを選ぶためのコマンドレット。

### `Sort-Object`

データを並べ替えるためのコマンドレット。

### `Measure-Object`

件数や合計、平均などを調べるためのコマンドレット。

### `Where-Object`

条件に合うデータだけを選び出すためのコマンドレット。
