# 鈴鹿黒窓小噺 00

## まずは黒窓を開いてみましょう

早速、黒窓を開いてみましょう。

Windowsキーを押して、上部の検索窓に **「ターミナル」**
と打ち込むと出てきますね。

```{=html}
<!-- スクリーンショット：ターミナルを検索している画面 -->
```
黒い画面が開いたら、こんな文字が見えていると思います。

``` powershell
PS xxx >
```

`xxx` の部分は、それぞれのPCの環境によって異なります。\
画面と同じでなくてもご心配なく。

## まず、ひとつ指示してみる

さっそく指示を与えます。

`PS xxx >` のところを **プロンプト**
といって、黒窓が「指示を待っている状態」です。

ここに、

``` powershell
date
```

と入れて Enter を押すと――

```{=html}
<!-- スクリーンショット：date の実行結果 -->
```
今日の日付が出てきました。

今度は、

``` powershell
1..10
```

と打ち込んで Enter を押してみましょう。

```{=html}
<!-- スクリーンショット：1..10 の実行結果 -->
```
指定した範囲の数字が縦に並びました。

こんなふうに画面に指示を与えて働かせるのが、このターミナルの黒窓の役割です。

（本当はもう少し込み入った説明があるんですが、それはまた次のお話で......）

## もう少し働かせてみる

先を続けます。

今度はプロンプトに、

``` powershell
get-process
```

と入れてみると――

```{=html}
<!-- スクリーンショット：get-process の実行結果 -->
```
なにやらズラズラと出てきました。

これは、現在Windowsが実行している裏方の小さなプログラムたちの状態を、一覧で見せてくれています。

流れてしまった画面の上のほうも、マウスホイールをころころ回したり、画面右のスクロールバーをドラッグしたりすれば見ることができます。

## ↑キーを押してみる

さらに、もうひと手間加えてみましょう。

キーボードの矢印キーの **上（↑）** を押してみてください。

先ほどの、

``` powershell
get-process
```

が出てきましたね。

こんなふうに、この黒窓は過去に入れた指示を記録してくれていて、何度でも呼び出し、編集して使うことができます。

これは結構大事です。

毎回、全部を最初から打ち直さなくてもいいんです。

## 呼び出したものに、ちょっと足してみる

では、画面に出ている `get-process` の後ろに、

``` powershell
|ogv
```

と足してみてください。

つまり、こうです。

``` powershell
get-process | ogv
```

`|` は、キーボード右上にある `￥` 記号のキーを Shift
キーを押しながらたたくと入力できます。

この黒窓ではしばしば使うキーなので、憶えておいてください。

さて、どうなりましたか？

```{=html}
<!-- スクリーンショット：get-process | ogv の画面 -->
```
なんだかちょっと、Excelを思わせる画面が現れたと思います。

画面の `CPU` や `ProcessName`
などをクリックすると、表示の順番を変えることができます。

画面上部のフィルターに `host`
などと入れると、その名前が含まれたものだけを選ぶこともできます。

## 小さな道具をつないで使う

ここまでに登場した `get-process` や `ogv`、`date`
のようなものを、この黒窓では **コマンドレット** と呼びます。

小さな道具のように働くもの、と今は思っておいてください。

そして先ほど入力した、

``` text
|
```

これを **パイプ** と呼びます。

複数のコマンドレットをつないで、働かせることができます。

今回は、

``` powershell
get-process | ogv
```

でした。

`get-process` が集めてきたものを、パイプで `ogv` に渡して見やすくする。

まだ細かい仕組みは分からなくても大丈夫です。

まずは、

**「小さな道具を `|` でつなぐと、できることが変わるらしい」**

くらいで十分です。

## 今日はここまで

さて、黒窓ことコンソールを使って、ちょっとしたことをさせてみました。

まだまだ訳が分からないことばかりだと思いますが、少しは興味が出てきましたか？

もう少しお付き合いいただくと、だんだん面白さが出てくると思います。

是非とも、次の小噺でお会いしましょう。

## 本日のまとめ

1.  黒窓の正体は **コンソール**
2.  その中で動くのは、主に **コマンドレット** という部品らしい
3.  **パイプ `|`** でつなぐと、組み合わせて動かせるみたいだ
4.  **↑キー** で過去に入れた指示を呼び出し、再利用や編集ができる
5.  マウスホイールで、流れてしまった結果をさかのぼって見ることもできる

## 本日の用語集

**コンソール**\
今回「黒窓」と呼んでいる、文字でコンピューターに指示を与える画面。

**プロンプト**\
黒窓がこちらからの指示を待っている場所。今回は `PS xxx >`
と表示されていたところ。

**コマンドレット**\
PowerShellで使う小さな命令・道具。今回使った `Get-Process` など。

**パイプ `|`**\
前の処理から出てきたものを、次の処理へ渡すためのつなぎ役。

**Out-GridView（ogv）**\
結果を表のような別画面で見せてくれるコマンドレット。`ogv`
はその短い呼び方。
